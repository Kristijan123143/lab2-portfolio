# Lab 2 – Interactive Portfolio

Author: Kristijan Duspara
Target grade: 3

## Description

This project extends my Lab 1 portfolio with an interactive feedback form.
It uses HTML, CSS and vanilla JavaScript.

## Features

- Required name, email, topic and comments fields.
- Support for international names.
- Optional website field using browser URL validation.
- Live character counter with a 15-character minimum.
- Written error messages and red or green validation borders.
- Visible keyboard focus and accessible field descriptions.
- Personalized success message displayed for four seconds.
- Complete form reset after successful submission or when Clear is pressed.
- Responsive layout and support for reduced motion.

## How to run

Open index.html in a modern web browser.

No installation, build tools or backend are required.
The form does not send or save any data.

## Main files

- index.html: portfolio content and feedback form.
- style.css: layout and visual states.
- feedback.js: validation, character counter and form interactions.

## Testing

Check empty and invalid submissions, valid submissions, the character
counter, the optional website field and the Clear button.

Test the page at mobile and desktop widths, navigate using the keyboard,
and check the browser console for errors.
